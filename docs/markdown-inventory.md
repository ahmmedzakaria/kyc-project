## Lifecycle rules

- **Indexed** means the file is retained in this catalog; it is not a claim that
  its technical content is current.
- Record a future decision as keep, replace, archive, or remove only after review.
- Before removing a row, record the replacement or deletion rationale in the
  relevant topic index.
- `AGENTS.md` files are operational agent instructions and are intentionally
  inventoried separately from product documentation.
